## ✨ Features
- **Cinematic UI/UX:** Premium glassmorphism design with an interactive, animated terminal and custom cursors.
- **Dark/Light Mode:** Seamless theme toggling engineered with `next-themes`.
- **Dynamic Case Studies:** Detailed architectural breakdowns and technical challenges documented via dynamic routing (`/projects/[slug]`).
- **Live GitHub Integration:** Real-time data fetching mapping repositories and stack preferences.
- **Performance Optimized:** Achieving near-perfect Lighthouse scores through Next.js Image Optimization and dynamic rendering.

## 🛠 Tech Stack
- **Framework:** Next.js 14+ (App Router)
- **Styling:** Tailwind CSS + shadcn/ui
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Running Locally

1. Clone the repository
```bash
git clone https://github.com/baburathod/ramavathbabu.dev.git
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
